# The University of Texas at San Antonio (UTSA) - NCCDC Team Repository

This is our team repo including our prepared ccripts, configs, and templates to be used during the NCCDC event.

`2026_Linux` and `2026_Windows` directories include their own README.md for more detailed explanations on the contents.

## Contents

### 2026_Linux
Enumeration and hardening scripts for securing Linux systems during competition. Also includes utilities such as hash compare script, internal monitoring dashboard creation. 

### 2026_Windows
This directory contains our Windows enumeration and hardening scripts, including Sysmon endpoint logging configs and WDAC (Windows Defender Application Control) policies.


### Graylog
While we will leverage Splunk during the competition, this directory contains an additional `graylog` deployment setup for log management and SIEM purposes, including a docker compose file and some configuration rules. 

### Incident Response
This directory contains some simple templates for documenting and responding to incidents during competition.
